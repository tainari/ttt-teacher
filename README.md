# ttt-teacher：ネットがネットを教える（三目並べ）

小さなニューラルネット（教育者）に、別のニューラルネット（新人）の学習率を決めさせる実験です。
新人は三目並べの「完ぺきな手」を学びます。教育者は、新人の学習の様子を見ながら、15回の直しごとに学習率を決め直します。

必要なものは Python と NumPy だけです。GPUは使いません。

実験のいきさつと考えたことは、記事に書きました：[ネットがネットを教える仕組みを、三目並べで一から作ってみた](https://zenn.dev/tainari/articles/ttt-teacher-net-teaches-net)

## しくみ

- **新人**：入力18 → 中間の層（tanh）→ 出口（9つの手＋形勢）。重みは新人ごとにでたらめな数から始めます。素の勾配降下法で、1回の研修は300回の直しです。
- **教材**：三目並べの途中の盤4,520通りと、総当たりで求めた完ぺきな手。3,616盤を研修に、904盤をテストに使います。
- **教育者**：入力4〜5個 → 8（tanh）→ 1。数字は49〜57個です。見ているのは、研修の進み具合、いまの損失、損失の変わり方だけです。出力を学習率（0.003〜6.3）に直します。
- **教育者の成績**：育てた新人が、テストの盤で完ぺきな手を一番手に選べた割合。
- **教育者の育て方**：進化戦略（鏡像サンプリング）。教育者を少し変えた写しを32個作り、同じ新人たちを育てさせ、成績の良かった向きへ教育者を動かします。

## 実験1：全員が同じ作りの新人（32ノード）

教育者を1時間育てました（895ラウンド、のべ約8.6万回の研修）。育てるときに使っていない新人200人でくらべた結果です。

| 教え方 | テストの点 |
|---|---|
| 教育者のネット | 93.2% |
| 教育者の平均の動きを、全員に同じように当てる | 93.1% |
| 手で選んだ一番（4.5で始め、後半に1/8まで下げる） | 92.6% |
| 学習率ずっと2.0 | 90.3% |
| 学習率ずっと1.0 | 86.0% |

- 手で選ぶ側は、ずっと同じ7通りと、下げる形14通りを試したうちの一番です。
- 教育者は手で選んだ一番を0.7点上回りました（標準誤差 ±0.15点）。
- ただし、教育者の平均の動きを全員に当てても同じ点でした。**新人ごとに教え方を変える効果は見えませんでした。** 教育者は「良い形を1つ見つけた」だけでした。

## 実験2：作りがばらばらの新人

新人のノード数（8・32・128）と教材の量（3,616盤・300盤）を変え、6種類を混ぜました。教育者には種類を教えません。1時間育てました（425ラウンド、のべ約8.2万回の研修）。

**教育者は、種類を教えられなくても、ノード数に合わせて学習率を変えるようになりました。** 育てるときに無かった種類（太字）にも、なめらかに合わせました。

| 新人のノード数 | 教育者が選んだ学習率（始め → まん中 → 終わり） |
|---|---|
| 8 | 3.3 → 2.7 → 1.4 |
| **16** | 3.3 → 2.5 → 1.1 |
| 32 | 3.3 → 2.3 → 0.8 |
| **64** | 3.3 → 2.0 → 0.5 |
| 128 | 3.3 → 1.7 → 0.4 |
| **256** | 3.3 → 1.3 → 0.3 |

しかし、点はほとんど上がりませんでした。

| 教え方 | 育てた6種類（300人） | 無かった6種類（300人） |
|---|---|---|
| 種類を知っている人（種類ごとに手で選んだ一番） | 84.7% | 89.5% |
| 全員に同じ形（手で選んだ一番） | 84.3% | 89.3% |
| 教育者のネット | 84.2% | 89.4% |
| 教育者の平均の動き（新人を見ない） | 84.0% | 89.1% |

- 新人を見ない場合との差は、+0.17点（±0.10）と +0.27点（±0.08）でした。
- 手で選んだ1つの形との差は、−0.11点（±0.14）と +0.04点（±0.13）で、変わりませんでした。
- 理由：この問題では、「種類を知っている人」と「全員に同じ形」の差がもともと0.2〜0.4点しかありませんでした。完ぺきに見分けても、得がほとんど無い場面でした。

くわしい出力は [results/exam_var.txt](results/exam_var.txt) にあります。

## 分かったこと

- 学習の様子（損失の動き）だけから、相手のネットの大きさを見分けて教え方を変えることは、49〜57個の数字の小さなネットでも覚えられる。
- 見分けられることと、それで成績が上がることは別。上がるかどうかは、「相手ごとに合う教え方がどれだけ違うか」で決まる。
- 手で選ぶ側をていねいに探すほど、教育者との差は縮む。くらべる相手を弱くすると、教育者が実際より良く見える。

## 動かし方

```
pip install numpy

python teach.py 60        # 実験1：教育者を60分育てる → teacher_f300.npy
python exam.py 200        # 新人200人でくらべる
python exam2.py           # 教育者の平均の動きを全員に当ててくらべる
python exam3.py           # 手で選ぶ側に「後半に下げる形」を足してくらべる

python probe_var.py       # 実験2の下調べ：種類ごとに合う学習率は違うか
python teach_var.py 60    # 実験2：ばらばらの新人で教育者を60分育てる → teacher_var.npy
python exam_var.py        # 育てた種類と、無かった種類でくらべる（20分ほど）
```

育てた教育者（`teacher_f300.npy`、`teacher_var.npy`）を入れてあるので、最終テストだけを動かすこともできます。

## 注意

- 三目並べの小さなネットでの結果です。大きなネットや別の問題に当てはまるかは確かめていません。
- 学習率を学習させる研究は以前からあります（learned optimizer、メタ学習）。これは新しい手法ではなく、その考えを小さく作って確かめた記録です。
